# 对比算法库（milsim ↔ AFSIM 输出相似性）

编号对齐资料库文档《算法库方法梳理_四类》第 2 类「对比算法」，一算法一文件，
全部标准库实现（仅 `math`），零第三方包。每个算法的"算例数值"已与该文档
的示例交叉核对（`tests/test_cmp_metrics.py`）。

## 总览

| 编号 | 文件 | 一句话用途 | 本项目使用范围 |
|---|---|---|---|
| 2.1 | `time_domain.py` | 等长对齐序列逐点误差（MAE/MSE/RMSE/MaxAE/MAPE/余弦/斯皮尔曼） | 轨迹分量与首探距离的**绝对口径主指标** |

| 2.14 | `proportion_z.py` | 比例 Z 检验 | **二期**：命中率/达成率需大样本重复仿真 |

## 对拍口径约定

1. **AFSIM 输出不保证 1s 步长**（事件驱动/自有输出节奏）。等长指标
   （2.1/2.7/2.8/2.9）一律先过 `align.align_pairs`：取两序列共同时间窗、
   线性内插到统一等间隔栅格（默认 1.0s），**不外推**；栅格口径随结果落盘。
2. **两口径并用**：插值对齐口径（RMSE/TIC）评数值精度，原始点列口径
   （Fréchet 2.3）评形态/最坏偏差——后者不吃插值，可分离"采样稀疏成分"
   与"真实偏差成分"。
3. 二值序列（探测/通断）同样先对齐栅格再逐位对照（2.13），漏报/虚警计数
   必须一起报——率相同≠模式相同。
4. 首探距离：绝对口径（2.1 的 MAE/MaxAE）+ 相对口径（2.7/2.9）并用。

## 各算法要点

### 2.1 时域误差（`time_domain.py`）

- 误差记 `e_i = b_i − a_i`（a 待评、b 基准）；MAPE 分母取**基准值**，
  基准值过零直接报错（不静默跳过）。
- 斯皮尔曼：平均秩处理并列；"只看起伏顺序不看差多少"，A=[1,2,3,4]、
  B=[4,3,2,1] 给 ρ=−1。
- 交叉核对（文档 2.1 算例）：MAE=1.5、RMSE=1.6583、MAPE=1.4142%、ρ=0.9524。
  ⚠ 文档示例表里 "MSE 2.12500" 是笔误：按该组误差 e=[1,−3,−1,1,2,−1,−2,1]，
  MSE=22/8=**2.75**（RMSE=√2.75=1.6583 与文档一致），实现按 2.75。

### 2.3 离散弗雷歇（`frechet.py`）

- 动态规划 `dF(i,j)=max(d, min(dF(i-1,j), dF(i,j-1), dF(i-1,j-1)))`；
  与 DTW 的本质区别：DTW 求和（平均贴合），弗雷歇 max(min())（最坏一步决定）。
- sigmoid 相似度 `sim=1/(1+e^{5F})` 为库口径，**完全重合也只有 0.5**，
  判读以此为基准（平行偏移 1 → F=1, sim=0.0067）。
- 交叉核对：平行偏移 F=1.0；时序倒序的锯齿轨迹（点集全同）F=4.0——
  保序方法立刻识别"走反了"（Hausdorff 对同一对给 0，见 2.10）。

### 2.7/2.8/2.9 相对度量族（`tic.py`/`rmae.py`/`rrmse.py`)

- TIC 值域 [0,1] 由三角不等式保证；分母恒正（除非两序列全零——报错）。
- RRMSE 分母两种口径：恒正量（探测距离）用 mean，振荡信号用 rms；
  报告须写死用哪个。
- RMAE 取"参考幅值"口径（另有"基准模型 MAE"口径，数值不同不混用）。

### 2.10 Hausdorff（`hausdorff.py`）

- **不保序**：点集全同、时序相反 → H=0。只作空间覆盖辅助指标。
- MOD 变体把 max 换 95% 分位数：缓解单点支配，但离群占比低于分位数参数
  会被直接吞掉（漏报）；max 版至少不漏报。

### 2.13 二值匹配（`jaccard.py`）

- Jaccard 主口径（双 0 不加分）、SMC 对照口径；2×2 表的 b/c 即漏报/虚警。
- 两边都无事件（a+b+c=0）时 Jaccard 约定 1.0。
- 红线：0/1 数据禁用均值方差类方法。

### 2.14 比例 Z 检验（`proportion_z.py`）

- 正态近似条件 `n·p0·(1−p0)≥5` 不满足时返回 `approx_ok=False`，不擅自
  降级——换精确二项检验由调用方决定。
- 交叉核对（文档 2.14 算例）：k=70, n=100, p0=0.6 → z=2.0412, p≈0.0412。

```python
    align_pairs, rmse, tic, frechet_distance, frechet_similarity,
    jaccard_score, binary_match,
)

# 轨迹：milsim 1s 步长 vs AFSIM 不规则采样
t, a_xy, b_xy = ...  # 各自按时间戳取出的坐标分量
t, ax, bx = align_pairs(t_a, x_a, t_b, x_b, dt=1.0)   # 插值对齐口径
err = rmse(ax, bx); u = tic(ax, bx)                    # 数值精度
f = frechet_distance(pts_a, pts_b)                     # 原始点列口径
sim = frechet_similarity(f)                            # 最坏偏差 → 相似度

# 探测事件：两边逐 tick 0/1 序列（对齐后）

j = jaccard_score(det_afsim, det_milsim)
```
